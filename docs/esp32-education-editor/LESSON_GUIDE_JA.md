# 授業・教育利用ガイド

このガイドは、ESP32 Education Editor v0.6とFirmware v0.1.7を使った授業や学習活動を組み立てるための考え方と課題例を紹介します。特定の学年、授業時間、実施実績を前提にせず、利用する機器や学習者の経験に合わせて調整してください。操作手順は[Getting Started](GETTING_STARTED_JA.md)を参照してください。

## 対象と目的

ESP32 Education Editorは、ESP32-WROOM-32をブロックプログラミングで扱うための環境です。センサーから値を読み取り、条件に応じて処理し、LED、OLED、サーボなどで結果を表す活動に利用できます。

このガイドでは、完成した手順を一律に教えるのではなく、必要な基本操作と共通のミッションを示した後、学習者が予想・試行・改善を進める授業構成を提案します。活動の難しさや進め方は、使用する機器と学習者に合わせて選んでください。

## 「入力 → 判断 → 出力」の学習構造

プログラムを次の流れで考えると、センサー、条件分岐、出力の役割をつなげて扱えます。

1. **入力**：センサーやGPIOから値を読み取る。
2. **判断**：値を条件と比べ、何をするか決める。
3. **出力**：GPIO、OLED、サーボ、ESP-NOWなどで結果を表す。
4. **見直し**：実際の値や動作を予想と比べ、プログラムや条件を調整する。

例として、温度を読み取ってOLEDに表示するところから始め、学習者が決めた条件に応じてLEDの状態を変える課題に発展できます。条件値は活動の目的に沿って設定し、健康や安全に関わる判断基準として扱う場合は、信頼できる教材・基準を教師が別途確認してください。

## センサー値を読み取る

利用できる入力の例：

- **ESP32 DHT**：DHT11 / DHT22から温度・湿度を読む。
- **ESP32 Ultrasonic**：HC-SR04で距離を測る。
- **ESP32 GPIO**：GPIOのデジタル入力を読む。
- **ESP32 Connection**：接続状態、ESP32のMACアドレスやチャンネルを確認する。

まずは、値を読み取って変数や表示で確かめます。センサー値が変わる条件を一つずつ変え、プログラムが読む値と実際の状況を比べる活動にできます。

## 条件によって判断する

Scratchの制御・演算ブロックを組み合わせ、センサー値や入力値を条件と比較します。学習者には、実行前に「どの値ならどの処理になるか」を予想してもらい、予想と結果が異なった場合に条件やプログラムを調べる機会を作ります。

例：距離が設定した値より近いときと遠いときで、表示や出力を切り替える。設定値は課題の目的に合わせて学習者が決めます。

ESP32 Environmental Indicesで温度と湿度から環境指数を計算し、その値を条件ブロックに渡して動作を切り替える課題にもできます。

## LED、OLED、Servoなどへ出力する

- **ESP32 GPIO**：デジタル出力やPWMで外部回路の状態を変える。
- **ESP32 OLED**：センサー値や処理結果をSSD1306 OLEDに表示する。
- **ESP32 Servo**：サーボモーターの角度を指定する。
- **ESP32 ESP-NOW**：別のESP32へデータを送る。

出力を一種類ずつ試した後、センサー入力と組み合わせると、入力・判断・出力のつながりを確認できます。GPIO23を使ったLEDの基本例は[Getting Started](GETTING_STARTED_JA.md#6-最初のプログラムを作る)を参照してください。

## 基本課題と発展課題

### 基本課題：値を読み、表示する

DHTセンサーの温度・湿度、またはHC-SR04の距離を読み、画面やOLEDに表示します。どの値を、どの頻度で、どのように見せるかを考えます。

### 基本課題：入力に応じて出力を変える

センサー値を条件と比較し、GPIO出力やOLED表示を切り替えます。実行前に条件ごとの動作を表にしてから、ブロックで組み立てて試します。

### 発展課題：動作を組み合わせる

- DHTの値をOLEDに表示し、条件に応じてGPIO出力を変える。
- HC-SR04の距離に応じてOLED表示やServoの角度を変える。
- PWMの値を段階的に変え、出力の変化を比べる。
- Data Processingで複数の値や文字列を整形して表示・送信する。
- ESP-NOWで測定値を別のESP32へ送り、受信側で表示や出力を行う。

ここに挙げた課題は活動案です。センサーやアクチュエーターの具体的な配線・電源条件は、実際に使うモジュールの資料で確認してください。

機器の読み取りや出力を始める前に、該当する初期化・接続ブロックを使います。DHTはセンサー種別と信号ピンを設定し、HC-SR04はTRIG / ECHOピンを指定して接続します。OLEDは初期化し、Servoは制御するGPIOへ接続してから使います。具体的なGPIO番号は実際の配線に合わせてください。

## 学習者が自分で考える活動

共通ミッションを一つ示した後、次のような選択肢から学習者が課題を広げられます。

- 何を測るか、どの条件で動作を変えるかを決める。
- 数値をそのまま表示するか、メッセージや段階表示に変えるか考える。
- 条件値や繰り返し間隔を変えて、結果を比較する。
- 最初の予想と実測結果を記録し、違いの理由を調べる。
- うまく動かないとき、接続・入力値・条件・出力のどこを確認するか順番を考える。
- 追加したい機能を決め、ブロックを少しずつ加えて試す。

完成形を一つに限定せず、学習者が選んだ方法とその理由を説明できるようにします。

## 2人程度での協働活動

2人で取り組む場合は、例えば一人がブロックを組み、もう一人が予想・観察・記録を担当できます。課題の区切りごとに役割を交代すると、両方が操作と説明に関われます。

ESP-NOWの課題では、送信側と受信側を分担します。送信側が値やメッセージを送り、受信側が届いた内容を表示・利用します。どちらのボードが何を担当するか、チャンネルが一致しているか、データが届かない場合にどこを確かめるかを一緒に整理します。

## ESP-NOWを使ったボード間通信

ESP-NOWでは、2台以上のESP32間でブロードキャストやMACアドレス指定の通信を試せます。通信するボードは同じESP-NOWチャンネルを使用します。Firmware v0.1.7の起動時チャンネルは1で、設定したチャンネルは再起動すると1へ戻ります。

ボード間のESP-NOW通信には学校Wi-Fi、校内LAN、インターネット接続は必要ありません。一方、公開EditorとFirmware InstallerをWebから読み込むにはインターネット接続が必要で、Editorと各ESP32の接続はUSB / Web Serialです。ページを読み込んだ後に完全オフラインで使えるとは断定しません。

## 振り返りと評価の観点

完成した作品だけでなく、考え方や試行の記録も振り返りに使えます。例えば、次の観点で学習者の説明を聞いたり、記録を見たりします。

- どの値を入力として使い、どの条件で判断したかを説明できる。
- 条件ごとに期待する出力を予想し、実際の動作と比べている。
- うまくいかないとき、入力・条件・出力や配線を確かめて修正している。
- 追加した機能と、その機能を選んだ理由を説明できる。
- 協働時に役割を分担し、結果や気づきを共有している。
- 部品の接続や電源に注意して作業している。

これらは観察の観点の例であり、特定の学習効果や評価基準を保証するものではありません。実際の評価方法は授業の目的に合わせて決めてください。

## 授業前に教師が確認する事項

- 使用するボードがESP32-WROOM-32で、Firmware v0.1.7が書き込まれている。
- Chrome / EdgeなどWeb Serial対応ブラウザで公開EditorとFirmware Installerを開ける。
- EditorとInstallerのWeb読み込みに必要なインターネット接続がある。
- USBケーブル、ポート選択、Editorからの接続を事前に確認する。
- Arduino IDEのシリアルモニターなど、同じシリアルポートを使うアプリを閉じる。
- 使用するセンサー・表示器・モーターの資料を確認し、GPIO割り当て、電源、配線を準備する。
- ESP-NOWを使う場合、通信するボードのチャンネルを合わせる。
- 活動のねらい、共通ミッション、選べる追加課題、記録方法を決める。

## 安全面・配線上の注意

- 配線を変える前にUSBや電源を外し、通電中に回路を組み替えないようにします。
- ESP32のGPIOには5 Vを入力しないでください。HC-SR04のECHO出力は約5 Vなので、ESP32へ接続する前に抵抗分圧などで3.3 V以下にしてください。Firmwareリリースノートには抵抗分圧の配線例があります。
- LEDは電流制限抵抗を直列に入れるか、抵抗内蔵モジュールを使います。GPIOへLEDを直接接続しないでください。
- モーターやサーボをGPIOピンから直接給電しないでください。使用するサーボ・センサーの電源電圧、電流、配線方法は各モジュールの資料に従い、必要な電源構成を事前に確認してください。
- 部品の型番や接続方法が不明な場合は、配線前に教師が製品資料を確認してください。
